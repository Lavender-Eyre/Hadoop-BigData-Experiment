# Experiment 2: Inverted Index

## Environment

- Linux Ubuntu
- Hadoop 3.3.6
- Java 8


## Description

This experiment implements inverted index using Hadoop MapReduce.


## Dataset

10 English documents from public open source documents.


## Output

The program generates word-document mappings with occurrence counts.

Example:

hadoop <document01.txt>;<document02.txt>;<total,10>
